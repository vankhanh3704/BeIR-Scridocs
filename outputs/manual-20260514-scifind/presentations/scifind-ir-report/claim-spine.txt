Thesis:
BM25 is the strongest traditional retrieval method for the current SCIDOCS setup, while TF-IDF remains a fast baseline and LSA needs tuning to pay off.

Audience:
Instructor and classmates evaluating an information retrieval project.

One-line arc:
Start from the search problem, explain the dataset and retrieval choices, prove performance with metrics, then close with limitations and a path to hybrid semantic search.

Slide list:
1. Cover - SciFind turns SCIDOCS into a controlled comparison of classic IR methods. Proof: network visual + dataset rail.
2. Dataset - SCIDOCS evaluation depends on three linked tables: corpus, queries, qrels. Proof: data anatomy visual.
3. Method map - The four retrieval methods span exact filtering, lexical ranking, latent semantics, and probabilistic ranking. Proof: method matrix.
4. Preprocessing - Each method needs a different text normalization path. Proof: three-lane workflow.
5. Evaluation - Metrics separate accuracy, coverage, ranking quality, and first-hit quality. Proof: metric matrix.
6. Top-10 results - BM25 leads on Precision@10, Recall@10, NDCG@10, and MAP. Proof: grouped bar/table.
7. K sensitivity - Recall rises as K expands, while Precision falls across all methods. Proof: small multiple charts.
8. Interpretation - BM25 wins because it balances term frequency, rarity, and document length. Proof: method tradeoff map.
9. Demo - A clear query returns relevant citation-recommendation papers across methods. Proof: UI visual + top result.
10. Limitations - Current quality is bounded by lexical matching, preprocessing, LSA latency, and offline-only evaluation. Proof: risk map.
11. Future work - Hybrid retrieval can combine BM25 candidates, dense embeddings, and reranking. Proof: roadmap.
12. Conclusion - The project establishes a working IR baseline and a clear upgrade path. Proof: final scorecard + references.
